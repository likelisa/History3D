Presents from Past Civilizations

先看作品，再制作你的故事

两个案例展示同一件事：让壁画和文物背后的故事，成为可以观看、聆听和探索的体验。观看已有作品无需 API Key。

01 · 丝绸之路壁画

入画 · 张骞出使西域

跟随张骞西行，通过壁画、路线、人物与 Tripo 3D 场景理解故事。

  1. 进入作品，点击页面开始入口。
  2. 按故事顺序继续，观看持节西行与市场发现蜀物等场景。
  3. 对照原画与路线，按页面控制暂停、继续或切换章节。

这是围绕张骞定制的作品；第323窟壁画是后世的视觉叙述，3D 为艺术示意。

02 · 文物讲解

铜奔马

原照片、真实 Tripo 图生模型、三章九句讲解与九轨公开男声旁白。

  1. 进入作品，点击播放听讲解。
  2. 拖动旋转模型，滚轮缩放，或恢复镜头。
  3. 放大原图、跳到任意一句，展开故事查看依据。

模型共用一件静态 GLB。未见背面属于生成推断，不能当作扫描原件。

03 · 通用制作工具

文物与壁画讲解工坊

选择素材类型，上传原图，填写主题、史料摘录和模型配置。工具整理逐句故事，生成 Tripo 资产并组合讲解网页。已配置声音环境时生成固定旁白，否则提供阅读模式。

打开制作工具 →先看使用指南

点击工具里的“开始自动制作”会调用你配置的模型与 Tripo 服务，按制作范围消耗费用或积分。

本页是本机体验入口。已有作品沿用保存的素材、模型和音轨；新项目的生成质量需要创作者逐句查看。
