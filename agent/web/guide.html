按四步填写，制作一个讲解网页

只想观看作品，可以直接体验张骞壁画和铜奔马，不用填写任何字段。

1．主题与原图

选择“壁画”或“文物”，上传 PNG / JPG 原图（最大 8 MB）。主题说明你想让观众理解什么，避免只写“介绍这张图”。文物的名称、年代、材质、尺寸和收藏信息可选，只填写已知资料。

  • 壁画示例：从这张洞窟照片中可见的造像和千佛排列出发，解释它们与洞窟年代的关系；照片无法确定方位的部分不要定位。
  • 铜奔马示例：结合原图和史料，讲清铜奔马的来历、腾空姿态和单足支撑，让观众分辨原图可见细节与模型补全。

2．可回查的史料

至少添加一条史料。来源 ID 会自动填写，保持每条不同即可。每条填写标题、原文摘录和可选链接；摘录直接复制与主题相关的完整句子，保留原字和标点。仅填网址不能替代原文。工具依据你提供的摘录规划故事，不会自动抓取网页并认证史料。

洞窟资料填写示例

标题：敦煌研究院 · 莫高窟第39窟

摘录：修建年代：盛唐（五代、西夏、清重修）

来源：打开敦煌研究院原文

这条资料可用于新建第39窟项目。当前张骞作品采用第323窟，不能把两个洞窟的资料互换。

文物资料怎么选

从中国国家博物馆 · 考古发掘品进入一件具体藏品的详情，复制与所上传文物一致的名称、年代及介绍，并保存详情页链接。

这是目录页，不是铜奔马详情。铜奔马应使用本件的馆方资料或已有项目中保存的来源，不套用其他藏品的介绍。

3．模型与生成服务

  • API 地址：填写故事模型服务提供的兼容接口地址；远程接口需 HTTPS。
  • 模型名称：填写该服务当前支持图片输入的模型名。
  • 模型 API Key：只粘贴完整密钥，不带“API Key：”等说明。
  • Tripo API Key：单独填写 Tripo 密钥，与故事模型密钥区分。
  • 旁白：不用填写声音 API。服务配置公开声音环境时生成固定男声；未配置时仍可阅读故事和观察模型。

密钥仅在页面及本地进程内存使用。服务重启后需要重新填写；不要写进主题、史料或共享文档。

4．制作范围与打开结果

第一次体验建议最多 1 个资产。需要限制积分时勾选 credits 停止上限并填写数值；图生主资产当前预计 60 credits，文生预计 50 credits，实际以提供方结算为准，故事模型费用另计。

  1. 检查原图、主题和摘录后，点击“开始自动制作”。这会提交生成请求。
  2. 在工作区查看进度、逐句讲解与生成记录，保存项目 ID。
  3. 预览就绪后，点击“打开讲解网页”，播放或逐句阅读，旋转模型、放大原图。
  4. 有错误时按具体提示处理。已有项目可通过“继续已有项目”读取；不要反复新建同一项目。

显示“旁白尚未配置”时使用阅读模式。提交结果未知时保留项目，核对提供方记录后再处理，避免重复生成。
