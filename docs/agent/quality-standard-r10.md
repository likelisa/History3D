# 壁画讲解 Agent 的项目质量标准

用户要求把张骞项目的经验和教训固定为规则，主代理已核读 [26 条规则与证据](mural-case-lessons-r10.md)。机器可读版本为 [quality-policy.json](../../agent/quality-policy.json)，按 A 采集并生成真实初版资产、B 审核整合、C 桌面网页、D 真实验收执行。原始候选文档保留为审查证据；本标准只约束本项目，不修改全局 skill、memory 或安全边界。

故事必须先让观众理解人物、目的、事件、原因与结果。壁画、地图和 3D 为它提供观察入口。未出现在画中的事件可使用完整原画作背景或匹配 3D；不得编造画面锚点。后世壁画、史书原文和艺术推定分别说明。用户提供的史料摘录只能证明输入内容，URL 只作导航，需人工核实来源和解释。

模型与 Tripo 凭据分别填写，仅放在本地服务内存。计划确认前不收费生成；资产预算、模型参数与任务 ID 冻结。未知提交先查任务，不自动重复 POST。初版 GLB 必须真实下载并保留原始字节、PBR/UV、哈希及任务回执；整合后的资产须在网页实际加载。所有人物、建筑与道具的比例、前轴、接地和角色含义需复核，不能以文件存在或 prompt 指定尺寸自证。

人物移动必须有真实步态、支撑脚和整身转向。未提供合格动作的场景可以明确呈现静态重建；不得用滑动静态人偶冒充走路。视角按事件选择，接见不硬加路人，问答不得任意改写史实。当前质量基准是张骞已确认的场景；新生成场景仍须逐项复核，结构测试通过不能自动满足这个基准。

声音先试听，再完整生成。用户已认可公开 Qwen 合成样本在本机 GPT-SoVITS 的复刻试听，并授权继续制作旁白；实际方式应记录为公开合成参考推理、使用克隆、未使用私人参考、不训练。屏幕正文保持原文，专名合成读音提示另记。全部句子都通过文本、字节、解码和时长检查后才切换新 manifest；部分轨成功不能混入旧音轨凑齐。短试听认可不代替全篇及专名听感检查。

字幕位于画布下方。时间线由实测音轨和阅读下限计算，先完成对应视觉动作，再完整播放叙述；切场、路线和拖动都保持确定性。只做桌面，不新增手机布局。

产出状态必须区分：草稿、结构检查通过、可预览、已人工复核、可交付。可预览页不等于达到张骞基准；任何缺失的动画、完整音轨、历史审核、自然播放、录屏或 ZIP 检查，都应列为待办。完整交接包含源码、锁文件、采用资产、音轨、来源、规则、运行说明及待办；排除凭据、私人录音、模型权重和推理环境。封包后在新目录解压运行，再核对采用版本。

规则文件是验收依据，不是验收结果。实际结果须绑定当前运行、版本和证据，未检查项默认 pending；旧失败和旧验证不可覆盖。最终网页仍需要人看画面、听声音、核史实。
