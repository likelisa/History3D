# 剧本驱动的文物与壁画视觉编排

这是待实现设计。当前 main 基线为 41db058；本次只精简通用播放器界面，未实现下述新合同、部位绑定或自动视觉验收。当前定制张骞作品采用第323窟；10月4日新增第39窟工具生成案例，其素材与史料单独保存。原图观察句已可使用 sceneId:null 切回照片，但精确区域、三维部位绑定和短语动作时间轴仍待实现。

## 核心顺序

输入与证据 → 剧本 → 逐句视觉意图 → 按需生成资产 → 实际资产部位绑定 → 镜头编译 → 音频时间轴 → 播放与逐句复核。

先写“观众需要理解什么”，再决定“看哪里”。镜头变化必须服务一个具体部位、对象或空间关系；相邻句子的关注点不变时保持镜头。

## 1. 输入与证据地图

- 原图、文物身份、来源摘录各有独立 ID，保留原件与哈希。
- 从实际原图提出语义对象和区域：马头、三条腾空腿、一足与鸟形支撑；壁画中某个人物、人物组、器物和建筑。
- 区域用归一化矩形、椭圆或多边形，记录标签、来源和是否经人工确认。现有 x/y 点不足以表达区域大小。
- 二维坐标基于原图有效像素区域，渲染时处理缩放、留白和裁切；原图不被永久涂改。

## 2. 剧本与逐句视觉意图

每句保留文本、事实/推断标签和原文依据，再新增独立的 VisualBeat。

```json
{
  "cueId": "cue-5",
  "intent": "理解三足腾空与单足支撑的关系",
  "presentation": "compare",
  "targets": ["horse-raised-legs", "horse-support-contact"],
  "primaryMedium": "image",
  "actions": [
    {"on": "phrase:三条腿", "action": "highlight", "target": "horse-raised-legs"},
    {"on": "phrase:另一足", "action": "highlight", "target": "horse-support-contact"},
    {"on": "phrase:形成腾空", "action": "show-3d", "target": "horse-support-contact"}
  ]
}
```

presentation 支持原图主画面、3D主画面和对照。它不由 subjectType 硬编码：文物也可以原图为主，壁画也可以展示独立3D器物。

## 3. 资产需求与生成

- 汇总所有 VisualBeat，按语义对象去重，决定复用什么、需要新生成什么。
- 原文物已具备合格 GLB 时，调镜头与标注不重新调用 Tripo。多个句子共用模型。
- 独立壁画人物或器物要建立清楚的原图区域/参考来源；生成的立体解释标为艺术示意，不声称精确还原。
- 若模型缺失剧本需要展示的部位，记录差异，优先回退原图；新生成作为独立候选，保留原模型和拒绝原因。
- 模型规划只是数据。实际收费提交继续由服务端状态机、凭据、预算和任务去重控制。

## 4. 生成后的部位绑定与镜头编译

剧本使用语义目标，不直接凭空输出最终 camera 数值。

- 模型加载后确认朝向、尺度和真实包围盒，建立与 GLB SHA 绑定的 AssetBinding。
- 目标可以是完整对象、已确认的子网格、局部三维包围区域或表面点。自动定位先产生候选，错误或不确定时允许人工调整。
- 2D锚点不能直接当作3D锚点。尚无3D绑定时只能圈原图，不显示假的表面标记。
- 从目标区域计算 lookAt、距离、视角和投影标记；标记跟随相机更新，目标被遮挡时隐藏或调整镜头。
- 按渲染图复核目标是否可见、是否被裁切、是否足够大、标注是否对准。近观镜头若与全貌没有实质区别，返回重编。
- 用相同的目标与镜头 ID 复用镜头；无叙事必要时不切镜头。

## 5. 主舞台与播放

- 一个主舞台承接原图、3D和对照；辅助视图小型常驻或随需要出现。
- 原图重点：原图居中放大，圈/框目标，3D退到辅助位置。
- 器物重点：独立器物进入中心，标注对象/部位，原壁画作为来源小图保留。
- 对照重点：两侧展示同一个目标，解释从二维可见细节到立体关系的变化。
- 音频生成并对齐后，把短语触发点编译成该音轨的时间点；动作时间轴绑定音频SHA，音频变更必须重编时间点。
- 暂停、跳句、拖进度时从绝对时间重建布局、标记和镜头，不能只依赖一次性事件。
- 每句最多一个主关注点；少量必要动作，不逐字闪烁、不按固定秒数机械切换。

## 6. 铜奔马首轮逐句落地

| 句子 | 主画面与动作 |
| --- | --- |
| 1 身份与尺寸 | 原图全貌或整体3D；简洁身份标签；尺寸来自馆方，不在生成模型上伪装测量 |
| 2–3 出土、墓主 | 保持全貌，字幕讲来历；没有对应图像时不凭空圈对象 |
| 4 昂首嘶鸣 | 原图圈头部；有可信头部绑定时对照3D头部近观 |
| 5 三足腾空、一足接鸟 | 先圈腾空腿，再圈支撑接触处，动作随对应短语 |
| 6 单足支撑 | 3D支撑点近观并标记；保留整体小图帮助定位；原模型不符合时用原图 |
| 7 同墓车马俑背景 | 若提供对应史料图片才展示；不把本件当成整个车马阵 |
| 8 旅游标志 | 有授权的实际标志资料才对照；否则保持全貌 |
| 9 未知部分 | 回原图，说明观察边界；不旋转背面当作史实证据 |

## 页面信息层级

核心只展示标题、主舞台、当前句、必要对象标签和播放控制。艺术重建性质在相关视图简短标注。完整故事/逐句来源默认折叠，资产来源默认折叠，任务ID/SHA/文件检查放在生成记录中。工程验收状态由作者界面与质量报告承接，不作为观众主页面的主要内容。

## 实施与验收顺序

先给铜奔马的第4、5、6句编排准确的原图区域、3D部位和镜头，完成暂停/跳句/倍速播放验证；再扩展合同与编译器，把这三句作为回归样本；最后接入壁画主舞台切换和按需资产生成。精简页面不能当作新pipeline已完成，视觉映射通过也不等于史实或听感通过。
