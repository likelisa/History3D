# 扣留营地与两名匿名人物的制作边界

本轮新增 `viewer/public/mural-assets/detention-camp.glb` 和 `viewer/src/mural/guard-variants.ts`。营地采用原项目 Blender 4.5.14 LTS 与512像素嵌入PBR材质的做法，中央8米见方保持Y0，不放器物。主毡幕入口位于Z=-4.25，木框、门帘、缝线、绳索、低木栏、陶器和干草用于提高画面可读性。

《史记》卷123所支持的主线是张骞被匈奴扣留多年、得妻有子、仍持汉节。具体营地形制、拘留安排、看守人数、器物位置和日常动作缺乏这一段的直接证据，均为制作示意。低木栏表示营地边缘，不宣称考证出了监狱结构。没有增添刑讯、枷锁、牢笼或具体冲突经过。

两名人物复用已经交付的真实Tripo匈奴人物，源文件SHA256为 `1802a80083cd118295717f6e405a5bc98b99a48406dd2074c1a580c7a591f47f`。没有新增生成请求或费用。两人并非两份不同的历史肖像，也没有据此推定民族面貌：较年长者增加朴素软毡帽、灰褐肩披、短灰须和鬓发，持下垂普通木棍；较年轻者增加深色帽带、斜皮带和腰袋，持下垂未张弦弓。木棍没有汉节的身份或意义。

帽、袍、腰带和裤靴的交叉参考沿用 [原匈奴人物研究](./xiongnu-character-reconstruction.md) 的X01–X04；弓具类型参考X05–X06。新增帽顶、肩披、须发、年龄、颜色、斜带、腰袋、弓长与持物位置属于形象区分的制作选择，不能据此认定当时守卫的制服、实际装备或身份。

技术上只克隆实例，在上身与袍摆区域用顶点色乘原衣料贴图；袖子、手部、面部、裤靴和原金属腰带不作全局染色。原始GLB、UV和材质保持不变，新实例继续使用原base/normal/roughness纹理。另增的衣帽与道具使用独立织纹材质。脚姿采用现有正向双轨校准并停在静态，两人头和身体由调用方整体转向，不单独扭头，也不做走路摆臂。

验证依据为项目输出目录 `outputs/mural-clarity/detention-camp-r4/` 中的营地重导入检查、守卫原图保护检查和并排预览。最终场景的站位、光照、遮挡与浏览器画面由集成验收另行核对。本记录为 `no_persist` 项目制作证据，不修改全局规则或长期记忆。
