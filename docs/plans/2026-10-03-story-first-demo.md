1. 解说按时间和因果重写：汉武帝求盟的背景 → 张骞受命 → 匈奴扣留十余年 → 脱身后继续西行 → 大宛、康居接力 → 月氏拒盟的原因 → 大夏市场发现 → 归途再次被扣 → 十三年后归汉 → 后续出使与影响。
2. 壁画放在后记：解释初唐画家怎样借张骞远行讲佛教来历，分清首次外交任务和后世问金人叙事。开头不要求观众先学会读画。
3. 中文旁白、英文字幕、章节、注释、地图位置、3D镜头同时更新。地图支持返程和后续外交；不把没有匹配3D的事件套进行路镜头。
4. 正文独立回源审校，保留推测与证据边界：妻子同行、十三年与十余年不同、身毒为询问和推测、乌孙未即时结盟。
5. 先用已获用户认可的公开Kokoro音色生成新版试听与完整预览，确保文字和音轨一致。Qwen3-TTS先评估短试听及语气指令，不开始训练，也不上传私人录音。

主要文件：`viewer/src/mural/story.ts`、`subtitles.ts`、`scene-beats.ts`、`cue-presentation.ts`、`presentation.ts`、`main.ts`，公开音轨 `narration-v8/`，对应测试与审校记录。

验收：每句可回答人物、目的、发生的事或结果；不了解壁画也能听懂整个经历；所有音轨与正文逐字一致；讲图像方位时确实显示原画；地图不提前返回或把副使路线算到张骞本人；3D动作先完成再播完整旁白；字幕在画布下方。
