# History3D：两个作品与制作工具

## 演示给谁看、怎么进入

快速体验从 `/experience.html` 开始：先进入 `/demo.html` 查看项目与工具 Demo，读取已完成铜奔马案例的实际输入、剧本和生成记录；再选择现有作品体验。无需 API Key，也不提交生成。创作者从同页进入 `/` 工坊，需要自己的故事模型和 Tripo 配置。仓库提供源码及现成媒体，本地运行方法统一为 `npm ci` → `npm run demo` → `http://127.0.0.1:5210/experience.html`。

这两个作品是两种体验场景，不能把“两个场景”理解成项目只有两个镜头。张骞作品本身有多个故事章节与 3D 场景。

| 作品 | 定位与素材 | 实际体验 | 文件入口 |
| --- | --- | --- | --- |
| 丝绸之路 · 张骞出使西域 | 定制故事；第323窟后世张骞壁画与《史记》《汉书》材料 | 从原画入故事，跟随西行、路线与市场发现；定制角色和场景 | `viewer/mural.html`、`viewer/src/mural/`、`viewer/public/mural-assets/` |
| 铜奔马 | 工坊实际图生案例；原照片、来源摘录、一件真实 Tripo 模型 | 三章九句讲解；原图对照、全貌/部位观察、旋转缩放、九轨旁白 | `artifacts/bronze-horse-r14/viewer.html`、同目录故事/模型/旁白 |
| 文物与壁画讲解工坊 | 制作工具；用户自行提供图片、主题、摘录和配置 | 故事规划 → 结构与引用检查 → 真实 Tripo → 网页；可恢复已有项目 | `agent/web/index.html`、`agent/contracts.ts`、`agent/server.ts` |

张骞作品的定制镜头与动画并非已经全部转为通用能力。铜奔马模型为静态观察，不能宣称铜马已奔跑。图生模型的背面、内部与补全细节属于推断。

## 建议演示顺序

1. 说明动心起意：在博物馆看见了物件和壁画，希望理解它们背后的故事。
2. 打开张骞壁画，演示进入作品、持节西行及市场发现蜀物，说明原画与史料如何帮助理解故事。
3. 打开铜奔马，播放一段、放大原图、拖动真实模型，说明 Tripo 带来的立体观察能力。
4. 打开工坊，选择类型并按指南填主题、图片和史料，展示通用制作入口。生成需要费用与等待；演示已有结果时说明其已预先生成。
5. 回到两个作品，说明观众可以直接观看，创作者可以继续制作。

## 项目地图

| 目录 | 现在负责什么 |
| --- | --- |
| `agent/` | 通用输入合同、模型与 Tripo 执行、恢复、旁白接入、网页模板与入口/指南 |
| `viewer/` | 定制张骞作品与其他查看器；Vite 编译到 `dist/` |
| `artifacts/bronze-horse-r14/` | 已生成铜奔马体验，含真实 GLB、原图、故事、音轨和质量记录 |
| `contracts/`、`packages/` | 采集/处理/展示交接协议及场景包；旧样例不当作参赛作品 |
| `collector/`、`processing/` | 资料交接和处理原型；不是普通观看者的启动入口 |
| `docs/agent/` | 工具运行、质量规则、已实现范围及待实现设计 |
| `docs/demo/` | 当前演示与接力指南、当日更新 |
| `.processing-data/` | 本机运行状态与原件，Git 忽略；不公开整个目录 |

`npm run demo` 先构建到 `dist/`，然后 Agent 同时提供壁画、铜奔马和工坊。静态服务只开放构建媒体与铜奔马包白名单，保留路径/符号链接限制。`/` 保持工坊入口，`/experience.html` 是作品导航。

## 制作新作品

查看网页 `/guide.html`，顺序为素材类型/主题/原图 → 原文摘录 → 模型/Tripo → 制作范围。工具不自动抓网页，不能只填来源 URL。第39窟官方页面是新项目的填写示例，不能替换第323窟张骞来源；国博考古发掘品是目录，需进入具体藏品详情。

新运行的状态和源资料单独保存。`preview_ready` 表示预览产生，仍需检查每句是否讲对、模型形态是否合适及全篇听感。精确二维区域、三维部位绑定和短语动作同步仍见[待实现设计](../agent/story-visual-pipeline.md)。
