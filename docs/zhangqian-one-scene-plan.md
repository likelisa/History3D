# 张骞归途：先做好“南缘绕行”一个场景

团队本轮收敛决定 · 2026-09-23

## 要验证的体验

用户站进一小段归途场景，能理解一件事：**张骞此前被匈奴拘留，为避免再次被俘，回国时试图沿南缘绕行；后来仍再次为匈奴所得。** 场景要有可感知的人尺度、路途环境和史料说明，不以六个地名立柱代替历史现场。

本轮只制作“改走南缘的一段路”。它是一个代表这段历史选择的场景单元，不绑定莎车、于阗、楼兰的具体城址或一天的行程，也不指定再次被俘地点。现有首页六站路线保留为**内容顺序原型**和来源索引；完成单场景后，再决定它是入口、背景，还是被新体验取代。

### 事实与表达边界

- 《史记·大宛列传》记载张骞返回时“并南山，欲从羌中归，复为匈奴所得”。它支撑绕南缘归途和再次被俘的核心转折；不提供此路段的坐标、具体地貌、建筑、衣物或被俘地点。
- 维基百科《张骞》整理前128年及葱岭、昆仑山北麓、莎车、于阗、楼兰的逐站顺序。具体路线、地名对应和年代仍需采集器核对更直接的资料。
- 本轮设计的道路、地形、光照、人物站位和体验长度均是空间示意。单个模型生成得像，并不构成历史证据。场景中的内容判断要标 `recorded`、`inferred` 或 `demo`，来源 ID 指向每一项具体判断。

出处：[《史记·大宛列传》](https://zh.wikisource.org/wiki/史記/卷123)、[《张骞》词条](https://zh.wikipedia.org/wiki/張騫)。

## 场景范围

体验顺序暂定三步，先用文案与灰盒验证，再投入精细资产：

1. **人在归途**：让用户看见可行走的前路和人的高度；简短说明张骞在返回汉朝。
2. **为什么改道**：在一个视角/路径转折点说明“希望避免再次被匈奴俘获”。用户走进示意南缘路段；不能用虚构地图证明某条实际岔路或道路长度。
3. **已知结局**：说明仍再次被俘。用文字和声音/画面收束，避免编造伏击过程、兵力、时间或被俘地点。

暂不做六站城市、城址建筑、商队交易、兵器冲突或礼物分享。任何道具或服饰进入场景前必须有参考资料，并注明其适用范围；未知项可先用中性占位。

**处理层当前进展**：除任务链和六站内容索引外，已有一段可走的山前概念路、三处讲述点、分层地貌、程序人物参照和一个优化的 Tripo 岩体候选。研究、资产与浏览器验收记录见 [研究笔记](zhangqian-south-detour-research.md)、[资产/场景验收记录](zhangqian-south-detour-qa.md)。历史尺度、人物考据、完整碰撞、正式设备性能与端到端现场层验收仍未完成。

## 单场景验收门槛

- **内容**：首次体验的用户不用读六站路线图，也能说清“为何绕行”和“后来发生什么”；能打开两处关键判断的来源。未知地点与演示设定有明确标签。
- **画面**：一个主要视角和一个人尺度视角都能看清路、人物参照和场景层次。关键模型正面、侧面、背面均通过人工查看；近景没有明显破面、浮空、重复贴图或穿插。
- **空间**：用户可以沿一小段路前进并回到起点；人物、道路和道具比例有依据；场景包重新加载后位置与故事点不丢失。
- **运行**：在约定演示设备上记录首次加载、帧率、模型大小和失败提示。以真实设备结果决定减面、压缩或替换，不用本机 build 代替体验验收。

这个门槛没有全部达到时，不扩展莎车、于阗、楼兰的新站点。优先修复用户看不懂的故事、缺证据的资产、失真的尺度和影响体验的性能。
