# 南缘路段：处理层资产与场景验收记录

2026-09-23 · 本机浏览器样例 · 场景包 `processing/demo/public/story/south-detour/`

## 已实施

- 场景被收成一段示意的山前路：远景连续山体，中景坡地与碎石，近景压实路面、岩体和人尺度剪影。山地与砾坡的组合来自塔里木盆地现代地貌资料；具体颜色、天气、道路和节点坐标均为演示设定，不是张骞所走地点的实测复原。
- `story.md`、`sources.json`、`entities.json`、`scene.json` 分离内容与摆放。三个讲述点分别讲归途、沿南山改道、后来再次被俘；第三点没有指认被俘地点。
- 总览可旋转缩放；1.7 米视角支持 W/A/S/D 和屏幕按钮逐步移动，横向被限制在示意路段内，能回到起点。讲述点、来源与场景同时显示；岩体加载失败时退回程序岩体。

## 当前验收与限制

- 本地构建、Python 场景包合同和 GLB 哈希/格式测试通过；本地浏览器确认三步讲述点、资料来源、模型状态、总览/行走切换、前进按钮、重置反馈。
- 页面显示瞬时 FPS 便于观察；它不等于约定设备上的稳定帧率或手机验收。后续需记录具体设备、首屏时间、持续帧率与内存。
- 目前横向限制是一段示意路的边界，不是完整物理碰撞。人物剪影未考证相貌和服饰，也不代表当时同行者数量。具体地形、气候、光照、人物器物与被俘地点均待资料支持；详细证据矩阵见 [研究笔记](zhangqian-south-detour-research.md)。

## 2026-09-24 · 三幕场景处理扩展

- `entities.json` 增加两名中性旅人、驮载剪影、货包、火堆、界石和两名远处追兵剪影；`scene.json` 给出各对象稳定 ID、米制摆放，以及 `performance.beats` 的三幕时间与动作说明。画面按该包加载对象，不把程序模型标成 Tripo 或史实资产。
- 演出依次包含沿路前行和货包晃动、在界石旁短暂停顿、继续前行后远处追兵接近与停步。末幕是象征性的对峙，**没有演出史料未载的袭击过程**；人物数量、身份、货物、具体位置和冲突细节均为 Demo 演示设定。
- 音乐使用浏览器 Web Audio 合成的低音持续氛围音，必须点击按钮才播放；不包含外部音源，也不宣称古代乐器复原。
- 场景切章时自动聚焦对应段落，可继续拖动观察、切人尺度视角或重置；旧的三步资料链接与 Tripo 岩体候选保留。
- 验收：本地 `cd processing/demo && pnpm build`、`processing/pipeline.py validate processing/demo/public/story/south-detour`；浏览器观察演出跨章与音乐开关。此验收是本地 Demo，不等于史实美术审核、移动端性能验收或生产发布。
