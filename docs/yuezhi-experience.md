# 张骞使月氏 · 空间故事首版

基线：dev `66e7a83`；实现分支 `feature/yuezhi-experience`。

## 运行

使用 Node 20+。本机已有 Node 22，系统默认 Node 16 不满足项目运行要求：

```sh
PATH=/opt/homebrew/opt/node@22/bin:$PATH npm run yuezhi:dev
```

打开 `http://127.0.0.1:5191/yuezhi.html`。日常启动只重新编排已有资产，不调用 Tripo。

## 用户体验（人物对话书页，r2）

以固定观察视角阅读四页：抵达月氏、交涉、停留一年多、大夏市场。场内点击“下一句”改变说话人物与对话；选择想问的问题，同一布景继续。每页读完后翻书进入下一场景。原漫游与预测题不在主流程中。

人物对白为据史料改编的现代语言，不是史书记载的逐字谈话。“记述”呈现史料内容的现代转述；当前句的依据与制作边界在“史料旁注”，已读内容可通过“回看本页对话”查看。

本地保存精确书页和对话节点。章节书页支持回看已读页；未读页须顺序翻开。r2使用独立存储键，原r1漫游进度不被覆盖。支持键盘空格／右箭头继续、Tab选择按钮，减少动态偏好会关闭背景待机与翻页动画。朗读使用浏览器TTS，默认关闭。

## 边界与验证

人物相貌、服饰、接见建筑、市场格局、角色身份及具体对白均为叙事示意。接见者不指定为某位王，不裁定太子／夫人异文；交涉页是对多次或长期交涉的压缩，不声称一次会面即正式拒绝。月氏与大夏是不同空间；停留一年多是区域活动，不代表固定王庭住宿或具体四季。蜀布不指定为丝绸，竹杖外形仍需考据。

内容保留draft，未做最终史料与用户外观批准。验证记录见 `records/yuezhi-book/`。本机默认并发测试遇到既有处理层测试超时，使用单worker与60秒默认超时跑完整88项通过；具体命令与日志保留，不能写成默认npm check全绿。构建和目标包校验另外执行。
