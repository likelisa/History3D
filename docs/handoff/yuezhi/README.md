## 对白互动与接力边界

在原对白区选择希望询问的话题，由当前在场的人物作答，再回到主线继续阅读。选项代表想听的不同话题，内容随当前情节变化：

| --- | --- |

| 接见 | 向月氏接见者问共同旧仇或远汉的顾虑，理解双方处境差异；没有路人参与决定 |

问答设计的逐项依据见 `04-问答设计审查.md`。继续修改时先判断前文是否已经说出答案、答者是否可能掌握信息、两个话题是否有区别、回答是否自然接上下一句；不要为增加按钮而重复信息或改变史实。

## 在伙伴电脑运行

解压到一个新的目录，进入 `History3D/`。需要 Node.js（本次验证为 v24.16.0）及 Python 3；正常查看已有模型不需要安装 Blender。`npm ci` 从锁文件安装依赖，需要访问 npm；包内不附 `node_modules`。

```powershell
npm ci
npm run yuezhi:prepare
npm run check
npm run build
npm run preview -- --host 127.0.0.1 --port 5193 --strictPort
```

打开 `http://127.0.0.1:5193/yuezhi.html`。开发时可在准备和校验后使用：

```powershell
npm run dev -- --host 127.0.0.1 --port 5193 --strictPort
```

包内保留实际源码、测试、fixtures、原始/精修 GLB、采集 delivery 和整合 package。`viewer/public/packages` 是运行时复制副本，`npm run dev` 或 `build` 会自动重建。包内排除 `.git`、`.processing-data`、本机缓存、依赖目录、编译产物、环境变量文件、凭据和 Blender 安装，因此不是带 Git 历史的仓库克隆。
