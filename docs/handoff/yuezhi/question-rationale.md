# 张骞故事问答设计依据（REV4）

采用原绘本的“选择想问的话 → 在场人物回答 → 继续故事”。每处提问须有当下动机、可回答的在场角色和信息增量；不按页数凑数量，也不让选择改写已有历史结果。当前共五处：抵达、接见、停留各一处，市场两处。

| 情节 | 问题与角色 | 对当前故事的作用 | 依据与边界 |
| --- | --- | --- | --- |
| 抵达 | 向当地协助者问月氏为何迁来、与大夏有何关系 | 先认识目的地的来历和政治背景，再说明出使来意 | 《史记》记月氏原居敦煌、祁连间，被匈奴击败后远迁，西击大夏而臣之；具体接引人与问答为改编 |
| 接见 | 向月氏接见者问共同旧仇或相距汉朝遥远的顾虑 | 解释汉廷结盟期待与月氏当前处境的差异 | “地肥饶，少寇，志安乐，又自以远汉，殊无报胡之心”；不冒充谈判原话、不设结盟成功分支 |
| 区域停留 | 向当地协助者问月氏或大夏的生活方式 | 补足不同区域的生活背景，自然走向大夏见物 | 月氏“随畜移徙”；大夏“其俗土著，有城屋”“有市贩贾诸物”；不补具体每日行程 |
| 大夏见物 | 向大夏答问者问蜀布或邛竹杖的来处 | 从熟悉物品发现远地往来，引出商人在身毒购入 | 见物与“吾贾人往市之身毒”有记载；答问者不能自动认定为售货商人，不补价格、纤维或亲走货路 |
| 身毒追问 | 向同一答问者问身毒的方位或风土 | 在首次提到身毒后获取新信息，支撑张骞的道路推想 | “身毒在大夏东南可数千里”“其俗土著，大与大夏同，而卑湿暑热云”；保持传闻口吻，不说张骞亲至身毒或已走通路线 |

删除了抵达重复问旧仇与距离、接见再问安定与距离、停留泛泛建议看市场三处；市场重复确认产地与购入地改为上表的身毒追问。原主线节点、旧四选项身份及每页固定结尾保留。选项代表要听的不同话题，回答后合流，不是对错题或历史走向的投票。
