## 讲述定位与史实边界

视觉主线是初唐莫高窟第323窟《张骞出使西域图》。壁画距离汉代出使约七八百年，使用了后世佛教叙事，把金人、问名号、僧人与佛塔连在一起。

判断汉代出使目的与经历，优先依据《史记》《汉书》等并交叉核对，不把任何单一文献直接等同于完整史实；理解初唐如何重述张骞，则以壁画及榜题为直接材料。首次求盟、扣留、月氏求盟未成、大夏见闻属于文献背景；金人被画为佛像、寻问名号、僧塔呼应属于壁画叙事。不能把画中的服饰、城池、僧塔直接当作汉代现场复原。

来源锚点：[敦煌研究院解读](https://www.dha.ac.cn/info/1266/2524.htm)。现有营地、王庭、市场陈设与人物动作均为展示补全；人物外观不认定为汉代标准制服或真实肖像。

当前仍是8章24句，已改为讲述者直接带读者看画、看旅途的导游口吻。尚未形成对两次出使、返程再次扣留、榜题年代错置等问题的完整讲述；这些是后续内容工作，不能称已经完成历史叙事重写。

## 当前最终采用的体验

- 开场直接出现Tripo使团，固定镜头；约1秒后开始第一句旁白，取消原先前5秒的大幅绕转。
- 底部为中英双语字幕，同步逐字呈现；音频仍为中文。字幕高度可选紧凑/宽松，字幕在画布外。
- 进度条支持拖动，支持暂停、上一段/下一段、章节定位以及0.8/1/1.15/1.3/1.5倍速度；整句音频完成前不会被固定章节时长截断。
- 右侧“你正在看原画的这里”与原画定位图保留。构图说明回到原画，路线说明穿插地图。
- 继续西行的地图覆盖整段对应解说，不再3秒切走；地图及标记是空间示意，图中包含副使与其他时期路线，不是精确首次出使轨迹。
- 金框只在旁白开始时短暂强调约3.5秒。已给确定角色加姓名，例如张骞、画中汉武帝；匿名随从、守卫、接待者不冒称具体历史人物。
- 第4/5章补环境与营地拦截、护送、出入受限动作；这些动作是展示示意。
- 市场保留原有摊位与中央蜀布/竹杖，新增布卷绑绳、开口编篮与粮食、陶器、货袋，以及摊主/来客手臂动作和慢行人流。镜头压低并靠近交易摊位，篮筐位置核对落在桌面上。
- 主标题仅保留“张骞出使西域图”。移除History3D品牌/副标题、水墨试验按钮、旁白/音乐开关，以及用户指定的“回看旅途”等提示；出处、史料、音乐授权仍在资料面板中。
- 旁白与音乐默认开启，按开始/暂停同步播放。背景音乐使用已有《At Rest》节选，独立低音量循环。

水墨滤镜曾作为试验接入，但用户认为泛白纸纹遮罩影响观看，最终已移除全部屏幕后处理，直接渲染原有场景材质。保留场景本身的壁画色系，不要恢复已撤掉的实验开关或泛白滤镜。

## 在队友电脑运行

取PR 12基线和本轮PR的完整源码，使用锁文件与Node 22.12+：

```sh
npm ci
npm run check
npm run build
npm run preview -- --host 127.0.0.1 --port 5194 --strictPort
```

访问 `http://127.0.0.1:5194/mural.html`。两个试验入口分别是 `/tripo-lab.html`、`/zhangqian-mural-trial.html`。普通运行不需要Tripo/Noiz密钥、Blender或语音推理模型，也不会新建付费任务。

需复现语音/真实生成时才使用作者脚本，凭据由各自配置到仓库外；不要在构建流程中自动调用生成。张骞作者脚本有提交意图锁，未知结果不自动create第二次。
