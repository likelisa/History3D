# 张骞归途：史实范围与空间表达

`/journey` 保留前一轮的六站路线索引。当前首页已转为 [南缘归途单场景](zhangqian-south-detour-research.md)，优先验证一段可走的历史选择。

该旧路线原型选取张骞第一次出使西域后、元朔元年（前128年）启程归汉，到归途中再次被匈奴俘获这一段。体验按阅读顺序拆成六个节点：启程、南缘绕行、莎车、于阗、楼兰、再次被俘。

**当前下一轮决定：**六站路线保留为内容索引，制作重点转为“南缘绕行的一段路”，不继续增加站点。具体制作单与验收门槛见 [单场景制作计划](zhangqian-one-scene-plan.md)。

## 文本依据

- [《史记·大宛列传》张骞段](https://zh.wikisource.org/wiki/史記/卷123)：张骞从大夏一带停留岁余后返回，沿南山想从羌地回去，再次为匈奴所得，后又被扣留岁余。它支持“绕南缘归途和再次被俘”的核心转折，未给出这里每一站的路线坐标或被俘精确地点。
- [维基百科《张骞》第一次出使西域](https://zh.wikipedia.org/wiki/張騫)：整理前128年启程回国、经葱岭与昆仑山北麓绕行、经莎车、于阗、楼兰、再次被俘并被扣留一年。这里的逐站顺序和年份依据此二手叙述；上线前仍需进一步核对更直接的史料及地名对应。

## 页面怎样使用这些资料

`public/story/zhangqian-return/` 保存 `story.md`、`sources.json`、`entities.json`、`scene.json`。事实节点保留来源 ID；前端按 scene.json 的故事点顺序和对象摆放数据呈现。处理层合同校验脚本把这一包当作真正的交接案例，确保来源和对象引用有效。

三维场景是非比例的叙事模型：山形、地面纹理、节点间距、路径宽度、人物轮廓、模型尺寸和路线弯曲都没有历史或测绘依据。它们只帮助读者识别“绕行”和“途中再次中断”这两个关系。最后的被俘节点是叙事终点，**没有指认被俘地点**。页面不把这些示意资产当作史实。

验收时请依次点击六个节点，检查场景选中、右侧事实叙述与来源是否同步；切换“路线总览”和“站到路线中”，确认两个视角都可用；最后一站必须显示“地点未定位”。原先用于技术交接的虚构渡口故障案例保留在 `/cases`。
