# Presents from Past Civilizations

给今天的人，一份来自历史世界的礼物。项目包含两个可直接观看的作品，以及制作新讲解网页的通用工具。

## 快速体验

**先看项目与工具 Demo，再体验已有作品；想制作新故事时，再进入工坊。** Demo 和已有作品不需要 API Key，使用仓库中保存的原图、真实 Tripo 模型与音轨。

### 新电脑：从源码启动

准备 Node.js 22+（推荐 Node 24）和支持 WebGL2 的桌面浏览器。在终端执行：

```bash
git clone https://github.com/likelisa/History3D.git
cd History3D
npm ci
npm run demo
```

已有源码时，在项目根目录执行最后两条命令即可。`npm run demo` 会校验并构建壁画作品，然后启动本地 HTTP 服务。终端保持运行，浏览器打开 **[统一快速体验入口](http://127.0.0.1:5210/experience.html)**。

已安装依赖、且已有当前版本的 `dist/` 时，可用 `npm run agent:dev` 直接启动。依赖安装需要网络；构建和观看保存的作品不会提交新的模型或 Tripo 任务。不要直接双击作品 HTML。

### 两个作品怎么体验

**丝绸之路壁画：** 打开 `/mural.html`，等待原画、模型和音轨准备好，点击“开始张骞的故事”。可暂停、继续、切换八个章节，或切换原画与对应 3D。重点体验持节西行，以及第5段“没带回盟约，却有新发现”的大夏市场。通过“壁画与史料”查看出处，路线图帮助定位远行过程。

**铜奔马：** 打开 `/examples/bronze-horse/viewer.html`，等待模型载入，点击“开始播放讲解”。拖动旋转、滚轮缩放，“恢复镜头”回到当前观察方向；“放大原图”进行细节对照。可以暂停、上一句/下一句、跳章节，展开“完整故事”与“3D 资产与来源”。保存的故事约83秒，模型是一件静态 GLB。

张骞是围绕第323窟壁画定制的故事作品；铜奔马是通用工坊的真实生成案例。后世壁画与生成模型用于帮助理解，不是首次出使现场或文物扫描。第39窟是另一个工具测试素材，与张骞作品分开管理。

### 制作新故事怎么体验

1. 打开工坊，选择“壁画”或“文物”，上传 PNG/JPG 原图，写清想让观众理解的主题。
2. 添加可回查的史料：标题、原文摘录和链接。网页指南提供字段说明、洞窟与文物填写示例；只填网址不能替代摘录。
3. 填写支持图片输入的故事模型地址、模型名称与 Key，以及独立的 Tripo Key，设置最多资产数和可选积分上限。
4. 点击“开始自动制作”后，在工作区查看进度；预览就绪后点击“打开讲解网页”。这一步会调用配置的服务，产生模型费用或 Tripo 积分消耗。

新项目配置公开声音环境后生成固定男声旁白；未配置时使用阅读模式。已有铜奔马音轨可直接播放，不依赖新生成的声音服务。工具目前依赖用户提供史料，不会自动联网完成史料认证，也不会复制张骞作品全部定制动作。
