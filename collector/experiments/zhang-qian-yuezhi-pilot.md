1. 打开 `story.json`，检查 `status` 是否为 `draft`，`storyId/contentRevision` 是否与 `sources.json` 一致。**预期**：`zhang-qian-yuezhi-pilot/1`，没有 `reviewed` 字样。

6. 可让技术同伴在仓库根目录运行 `npm run validate:collection -- collector/experiments/zhang-qian-yuezhi-pilot`。**预期**：退出码 0、`✓ 未发现问题`；这只证明 JSON 结构和本地引用存在，不证明历史真实性。
7. 检查 `collector/output/` 或 B 的交接 API。**预期**：这个试点**不会作为已发布包出现**。若看到它被正式交接，即为失败。

## 独立审查 agent 的通过指标

逐项给 `PASS/FAIL/BLOCKED` 和可复核证据：①结构校验零错误；②四条原文短摘录逐字命中（4/4）；③四个可追溯断言和一个未知断言无错误来源绑定；④异文被显式指出、没有被 Jev 或示意图抹平；⑤数字站点未被误作四个独立史料；⑥`draft`、权利待确认、无对象简报、无真实 B 消费被明确列为阻断；⑦搜索 provider/Jev/Tripo 此轮零实际调用，未写/输出密钥；⑧离线快照测试覆盖不匹配、篡改、缺轨迹和零公网调用。任一证据不足，不得写“史料合格/可正式发布”。
