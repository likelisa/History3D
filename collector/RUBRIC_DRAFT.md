# 采集层证据筛选规则草案（待史料负责人批准）

状态：`draft`。本文件和 `collector/src/policy.ts` 是工程门槛与校准提案，**不是已经批准的历史真实性标准**。当前默认 `RubricPolicy` 仍为草案，未提供有效批准人与校准记录时，流程停在 R，不输出候选三件套。

## 单位与结论

- 评审单位是**一个可定位的断言 × 一个来源中的一段原文**，不是整篇文章或整个场景。每个断言保存来源位置、原文摘录、适用范围和反向线索。
- 七维分别评 `0–3`，在 `collector/src/policy.ts` 的 `RUBRIC_ANCHORS` 有各自锚点。**不求和、不平均、不把分数表述为真实性概率。**
- `retain` 的最低工程条件：政策版本已批准、有校准记录、史料负责人逐维签名且每维带证据指针、七维都至少 2、原文摘录经独立核对、争议处理完毕、权利可支持本次用途。任一维低于 2 就进入 `needs_human`；人审可直接 `reject`，高分不能覆盖。
- `documented`、`inferred`、`illustrative` 不能混用。来源只支持其中一部分时拆成更窄的断言；模型生成的图不能作为历史证据。尺寸、数量、场景位置各自需要证据，不得由一篇泛泛的背景文章连带证明。

## 七维评审提示

| 维度 | 审核的具体问题 | 典型反例 |
| --- | --- | --- |
| 来源责任 `sourceAuthority` | 作者、馆藏/期刊、版本、发布责任能否核实？ | 匿名转载页包装成馆藏 |
| 断言相关 `topicRelevance` | 证据是否直接回答这个断言？ | 关于丝路贸易的总述被用来证明某行囊尺寸 |
| 原文可追 `originalTraceability` | 能否打开原文、定位页码/段落并复核摘录？ | 只有搜索摘要或 AI 转述 |
| 时空对象 `periodPlaceFit` | 时期、地点、对象是否匹配？外推是否说明？ | 晚期图像当作早期实物 |
| 来源独立 `sourceIndependence` | 多个链接是否其实抄自同一出处？ | 三个镜像网页被计作三证 |
| 冲突处理 `contradictionHandling` | 有无反向线索；若存在，是否定位并解释？ | Jev 选 A 后直接忽略 B |
| 使用权利 `rights` | 引用、图像、模型和再发布许可是否对应当前用途？ | 网页可看不等于素材可商用或改编 |

没有争议线索时不强求机械地制造“反方”；需记录检索范围和未发现反证的边界。发现可比的 A/B 证据时，Jev 只能回答被拆小的比较题；它选择 A 也不能代替原文核对、人审和权利审查。Jev 选择 B 或 `unclear`，不能自动保留原断言。

## 待人工校准的最小案例集

以下是**规则预期**，不是已检验的历史事实。史料负责人需用真实来源补入原文位置、判分理由、争议记录，再批准政策版本。

1. **仅搜索摘要**：原文可追为 1；不得保留。
2. **跨时代图片**：时空对象为 0–1；不得把图上造型当作目标时期复原。
3. **三个同源镜像**：来源独立为 1；不得计算为三条独立证据。
4. **不相关的权威来源**：来源责任可到 3，但断言相关为 0–1；不得保留。
5. **明确反证**：必须保存 A/B 原文位置、窄判断及人审解释；Jev 偏向反证或无法判断时停下。
6. **许可未知**：即使原文支持断言，素材复用仍不得放行；必要时只保留事实引用、替换素材。
7. **单一可靠一手来源**：不因缺第二来源机械拒绝；需要限定证据覆盖范围并明确“未交叉印证”。
8. **示意行囊图**：只能作为 B 层建模概念参考；不能为尺寸、材质或历史包法提供 `documented` 证据。

## 检索与隐私边界

用户反馈原文可能含姓名、邮箱、私人资料。默认只在本地形成计划，每条查询的 `providerIds=[]`，不自动发送公共搜索源。若要搜索，由研究人员生成**脱敏、最小化**的检索词，逐条填写准确的 `providerIds`，审核查询→接收方配对、反馈 ID、故事版本和整个计划摘要后，才向指定源发送；缺失、越权或变化后必须阻断并重新审核，不能把每条词发给整批所有 provider。当前代码的 `SearchApproval` 是运行前审计门槛，**不是身份认证**；后续如暴露给远程用户，还需服务端权限控制和授权审计。不存在“配置了 provider 就能直接外发”的默认路径。

## 批准前必须补的证据

- 至少两名独立评审对同一批真实与反例断言逐维打分，记录分歧与仲裁；不能以本仓库合成测试代替。
- 核验真实来源的原文摘录、版本与权利；确认 `retain`、`needs_human`、`reject` 的误判代价与阈值。
- 负责人明确批准政策版本、日期及校准记录指针后，才将 `RubricPolicy.status` 设为 `approved`。

验证入口：`npm run typecheck` 和 `npx vitest run tests/collector-policy.test.ts tests/collector.test.ts`。这些测试证明**工程门槛**，不证明史料真实性或审核已完成。
